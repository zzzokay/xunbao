# 转弯补偿：能算就算、不能算保留原值 —— 方案与验证

> 一句话：**已有实测的 8 条一条不动（另有 3 条因公式偏差>5cm 也被闸门挡回原值）；
> 新增 47 个原本吃默认值 19 的组合改由公式算出；剩下 186 个继续保留原默认值。**
> 全程**不覆盖任何"公式与实测差 >5cm"的值**，对现有已调通的路线零风险。

## 0. 5cm 闸门（本次新增的安全线）

```
Tier1  表里有这条三元组                        → 用实测值
Tier2  规则命中 且 |公式 − 实测| ≤ 5cm          → 用公式
Tier3  其它                                    → 保持原默认 19
```

注意顺序：**先看表里有没有实测值，有就比对公式；差超过 5cm 就直接放弃公式、用实测值。**
这条闸门让整个机制**自保护**：以后每补一条实测数据，只要公式与它矛盾，就自动退回实测值——
可以放心地一条一条加数据，不会因为公式把这个点改坏。

## 1. 判据：什么样的"能算"

三条同时满足才算（`Navigation/map.c` 的停车原地转分支）：

| 代号 | 条件 | 为什么 |
|---|---|---|
| **R1** | 入边 `func ∈ {NONE, DOOR}` | 传感器板还在**平地**上。跷跷板(QQB)/山(BHM/Hill)/桥(Bridge)/平台(UpStage/BLBS/BLBL/SM/BSoutPole…) 上板子离地或姿态改变，**检测时刻不可预测** |
| **R2** | 入边 `step ≥ 20cm` | `map.c` 的到达门槛是 `里程 ≥ 0.7×step`；`step≤18cm` 时只有 0.7~12.6cm，**车会被里程提前放行**，补偿实际在补段长，跟转弯几何无关 |
| **R3** | `100° ≤ |转弯| < 178°` | ① 小角度走"陀螺不停车转"分支，几何项 `1−cosφ` 太小（<0.1）② ≥178° 是原路折返，转身由平台函数/门逻辑处理，不该再加补偿 |

## 2. 公式与参数

```
Δ = L × (1 − cos φ) + d(判据)

L = 19.0 cm        ← "旋转中心 → 传感器板中心"的纵向距离（与现有默认值一致）
d(CRIGHT) = +11    ← 5 个样本
d(CLEFT)  =  −4    ← 4 个样本
d(DLEFT)  =  −5    ← 3 个样本
d(其他)   =  −4    ← 缺省
```

标定用的 9 条（平地 + `step≥20` + `100°≤φ<178°`）反解出的 `L`：**中位 17.0、均值 19.2、范围 11.0~35.1**，
子集内 `1−cosφ` 与实测值相关 **r = +0.70**。取 `L=19` 与现有默认值吻合。

## 7. 落地形态（供实现时参考，本次不改代码）

在 `Navigation/map.c` 的 `GetForwardDistanceBeforeTurn()` 里：

```c
/* 表中已实测的三元组：查表（16 条生效 + 2 条死值待清理） */
static const struct { u8 last, now, next; float dist; } kTurnTbl[] = {
    { B9, N7, P6, 25 }, { N10, N9, B9, 48 }, { B8, N9, C3, 0 }, { C4, N20, P8, 35 },
    { P8, N20, C4, 30 }, { N8, N5, N4, 36 }, { N8, N3, N4, 30 }, { N4, N3, N8, 20 },
    { N3, N4, B2, 30 }, { N13, N18, B5, 60 }, { N20, C4, B11, 25 }, { N5, N8, N12, 20 },
    { P6, N7, B8, 20 }, { B2, N1, P1, 25 }, { N8, N3, P3, 24 }, { C4, N20, B6, 24 },
    /* 原表里那 4 条因进错分支而永不生效的死值：B3→N2→P2=24、N8→N3→P3=18、
       B8→N9→N10=30、B2→N1→P1=18、N5→N12→N11=5、N4→N5→N12=6 —— 建议本轮一并清掉 */
};

#define TURN_CALC_MIN_PHI   100.0f
#define TURN_CALC_MAX_PHI   178.0f
#define TURN_CALC_MIN_STEP   20.0f
#define TURN_GATE_CM          5.0f

static float GetForwardDistanceBeforeTurn(u8 last, u8 now, u8 next)
{
    float meas = 0.0f;
    u8    hit  = 0;
    for (u8 i = 0; i < sizeof(kTurnTbl)/sizeof(kTurnTbl[0]); i++) {
        if (kTurnTbl[i].last == last && kTurnTbl[i].now == now && kTurnTbl[i].next == next) {
            meas = kTurnTbl[i].dist; hit = 1; break;
        }
    }

    /* Tier2：能算就算（平地 + 视觉到位 + 大角度） */
    {
        float phi  = fabsf(need2turn(nodes.nowNode.angle, nodes.nextNode.angle));
        u8    func = nodes.nowNode.function;
        float step = (float)nodes.nowNode.step;

        if ((func == NONE || func == DOOR) &&
            step >= TURN_CALC_MIN_STEP &&
            phi  >= TURN_CALC_MIN_PHI && phi < TURN_CALC_MAX_PHI)
        {
            float d = -4.0f;                                  /* 缺省 */
            if      (cur_method == ARRIVE_CRIGHT) d = +11.0f;
            else if (cur_method == ARRIVE_CLEFT)  d =  -4.0f;
            else if (cur_method == ARRIVE_DLEFT)  d =  -5.0f;

            /* cosf：M7 只有单精度 FPU，别用 cos */
            float calc = 19.0f * (1.0f - cosf(phi * 0.0174533f)) + d;

            /* 5cm 闸门：有实测值且公式与它差>5cm → 放弃公式，用实测值 */
            if (!hit || fabsf(calc - meas) <= TURN_GATE_CM)
                return calc;
        }
    }

    if (hit) return meas;      /* Tier1：实测值 */
    return 19;                 /* Tier3：保持原默认值 */
}
```

> `cur_method` 就是**节点检测函数要传出来的那个标志位**——它是 Tier2 的最后一块拼图。
> 在 `Task/ArriveDetect_task.c` 的 `deal_arrive()` 里记录"哪个判据命中"，随 `CROSS_EVENT_ARRIVED` 一起交给 `Navigation()`。
>
> **闸门是这套方案的关键**：有了它，以后每往 `kTurnTbl[]` 里加一条实测数据，
> 只要公式与它矛盾就自动退回实测值 —— 可以放心地一条一条加数据，不会因为公式把已调好的点改坏。

**陀螺不停车转那个函数（`GetForwardDistanceBeforeGyroTurn`）本次不动**——它 44 个组合里绝大多数是小角度，
现有表 + 默认 0 已经能用，而公式在小于 90° 时误差未经验证，动它风险大于收益。

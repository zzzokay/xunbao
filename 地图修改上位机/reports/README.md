# reports/ — AI 过程产物统一存放地

本目录只放**过程产物**：分析报告、方案草稿、定位/修复记录、逐日开发日志。

它们**不是项目文档**。归档前必须满足一个前提：**结论已经并入下面三份现状文档**，
本目录只是备查（"当时怎么查出来的"），不是唯一事实源。

- `项目讲解文档/project_reference.md` —— 项目现状（哪个功能在哪实现、怎么配）
- `项目讲解文档/README.md` —— 踩坑经验（§1~§8）+ 修改日志（§9）
- `项目讲解文档/交接专用文档（新人先看我）.md` —— 给接任者看的最终形态

## 规矩

1. **命名**：`YYYY-MM-DD_主题.md`（例：`2026-09-26_N14回程卡死定位.md`）。
2. **先沉淀再归档**：结论没进上面对应章节 → 先去那边写，再来这里放过程稿。
3. **本目录随时可以清空**（不像 `validate/` `tools/` 有常驻价值）。平时不用看。
4. **一次性垃圾不往这里放**：`.bak` / `__pycache__` / 临时 patch 脚本 / 编译产物，**用完直接删**。

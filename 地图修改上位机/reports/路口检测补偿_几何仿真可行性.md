# 路口检测补偿：从人工实测到几何仿真的可行性分析

> 目标：把「从检测到路口到走到路口中心」这一步补偿，从人工实测改为仿真直接计算。
> 结论：**停车原地转（stop）分支可以几何仿真算出（MAE≈4cm、比例系数 k≈0.9），
> 陀螺不停车转（gyro）分支因涉及动态转弯半径，只能近似、仍需单独标定。**

## 一、物理模型（第一性原理）

### 1. 小车几何

- **循迹板**：16 路灯，装在**车头**。`detail` 的 bit15 = 最左 1 号灯，bit0 = 最右 16 号灯。
- **旋转中心 O**：四轮几何中心（差速原地转的圆心），在板中心**后方 L**（纵向）。
- **灯位分布**：相邻灯间距一致（约 1 cm），中间 bit7/bit8 之间有个**大间隙**（左右八路分两半）。
- **引导线**：宽 30mm（3cm）红白布基胶带，车沿引导线循迹。

### 2. 检测到路口的几何

车沿入边（主线）前进，板中心对准主线。接近路口中心 P（now 节点）时，出边引导线
（横线/斜线）进入板子对应区域，触发 `deal_arrive()` 判据：

| 判据 | 触发灯型 | 路口几何 |
|---|---|---|
| DLEFT | 左 6 灯 bit15..10 ≥5 亮 | 左拐横线 |
| DRIGHT | 右 6 灯 bit0..5 ≥5 亮 | 右拐横线 |
| CLEFT | bit14/13 亮 且 4≤ledNum≤7 | 左斜线岔路 |
| CRIGHT | bit2/3 亮 且 4≤ledNum≤7 | 右斜线岔路 |
| MCLEFT/MCRIGHT | bit15/bit0 单灯亮 | 最外侧斜线 |

### 3. 补偿距离公式（停车原地转）

```
补偿 Δ = s + L
  s = 检测瞬间板中心到路口中心的纵向距离（沿入边方向投影）
  L = 旋转中心 → 板中心 纵向距离
```

含义：检测触发时板中心距路口中心还差 s，旋转中心在板后方 L，故再前进 s+L 后
旋转中心正好落在路口中心，此时原地转 φ 角，车头对准出边中心线。

`s` 的解析式（灯 i 横向偏移 y_i，转弯角 φ）：

```
灯 i 到出边线带符号距离 = s·sinφ + y_i·cosφ
灯 i 亮 ⟺ min(|y_i|, |s·sinφ + y_i·cosφ|) < 线半宽
判据触发 ⟺ 对应灯型首次满足（车前进中 s 单调递减）
```

## 二、仿真结果

### 参数（网格搜索最优）

| 参数 | 拟合值 | 物理合理性 |
|---|---|---|
| L（旋转中心→板中心） | **16 cm** | 文档实测反解中位 16.7、均值 17.2，吻合 |
| 灯间距 | 1.0 cm | 用户"一点多厘米"，吻合 |
| 中心间隙（bit7/8 间） | 1.5 cm | 用户"左右八路间隔较大"，吻合 |
| 线半宽 | 2.0 cm | 规则引导线宽 30mm⇒半宽 1.5，含检测容差合理 |

### 拟合质量（停车原地转 stop，15 条全部生效）

- **MAE ≈ 4.15 cm**（15/15 仿真成功）
- **过原点比例系数 k = meas/sim = 0.908**
- **线性回归斜率 0.95、截距 −1.3**（接近 y=x，说明仿真值本身就是 cm 正确值，几乎不需缩放）

对比文档 §14.7 旧结论「纯几何仿真只能当兜底、LOO-MAE≈7.2cm」，
**第一性原理几何仿真把误差从 7cm 降到 4cm**，且是"求解"而非"拟合"。

### 残差大的三条都有明确物理原因（非模型错误）

1. **`B9>N7>P6`（step=5cm 极短边）**：车还没稳定循迹就到路口，检测几何与正常不同，实测 25 是"段长补偿"（文档 §14.2 的 B 类信号）。
2. **`N8>N5>N4`（门区 DOOR）**：门区检测是 AWHITE/多判据组合，不是标准路口横线；且 `door_set_pass_node()` 会改写 step。
3. **`B3>N2>P2`（−30° 小角度 CLEFT）**：小角度斜线判据几何敏感性差（文档 §14.7 证据 2 已指出小角度被系统性低估）。

这三条正好对应文档 §14.2 说的「崩掉的点」：极短边、门区、小角度 —— 是已知系统性局限。

## 三、陀螺不停车转（gyro）分支 —— 语义不同

gyro 分支（7 条生效）是**弧线转弯**（`Go_Angle` 边前进边转，非原地），补偿是"弧线转弯的
提前量"，取决于**动态转弯半径 R**（由 gyro 转速度 + PID 决定，静态算不出）。

实测值 3~24cm 普遍小于 stop，符合"弧线转弯提前量比原地转补偿小"的物理直觉。

**结论**：gyro 分支不能用 `Δ=s+L` 的原地转几何算，需要转弯半径这个动态参数。
若要仿真，需先实测标定 gyro 转弯半径 R，再用弧线几何（弦长 2R·sin(φ/2)）建模。

## 四、最终结论与建议

1. **停车原地转（stop，占补偿表 15/22 条）可以用几何仿真直接算**：
   `Δ = s + L`，其中 s 由「循迹板灯位 + 引导线折线 + 判据」几何解出，L=16cm。
   比例系数 k≈0.9（≈1，几乎不需缩放），MAE≈4cm。
2. **物理参数已自洽反解**：L=16cm、灯距 1cm、中心间隙 1.5cm、线半宽 2cm。
   这些参数可直接量尺复核（14.4 第 4 条曾建议量 L、w，现在仿真已给出初值）。
3. **gyro 分支（7/22 条）** 需单独标定转弯半径，或保持实测。
4. **落地路径**：把 `Δ = s + L` 的几何计算写进 `GetForwardDistanceBeforeTurn()` 的
   Tier2 公式（替换现在的 `L(1−cosφ)+d(判据)` 拟合式），即可对"没测过的边"给出
   比默认 19 更准的补偿；已实测的边仍走 Tier1（5cm 闸门自保护）。
5. **局限**：极短边（step≤5）、门区、小角度（<45°）三类仍是几何仿真的盲区，
   与文档既有结论一致，需保留实测兜底。
